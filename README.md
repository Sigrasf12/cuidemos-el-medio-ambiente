# cuidemos-el-medio-ambiente
 Este proyecto busca promover el cuidado del medio ambiente mediante acciones que ayuden a reducir la contaminación y proteger la naturaleza.
 
- -Recomendaciones para cuidar el planeta:
- Separar los residuos para reciclar.
- Ahorrar agua y electricidad.
- Evitar los plásticos de un solo uso.
- Mantener limpios los parques y las calles.
- - Acciones para reducir la contaminación
- Utilizar bolsas reutilizables.
- Caminar o usar bicicleta cuando sea posible.
- Plantar árboles y cuidar las áreas verdes.
